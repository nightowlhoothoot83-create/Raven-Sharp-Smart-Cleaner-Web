# Raven Sharp AI File Manager — Web

Web interface hosted on Cloudflare Pages at cleaner.raven-sharp.com. It works in a browser on phones and PCs.

| Component | Repository / hosting |
|---|---|
| Web interface | This repository / Cloudflare Pages |
| Android app | `Raven-Sharp-Smart-AI-Cleaner`, frontend folder |
| Shared API | `Raven-Sharp-Smart-AI-Cleaner`, backend folder / Railway |

The Web and Android clients use the Shared API. The web API base is `https://raven-sharp-smart-ai-cleaner-production.up.railway.app/api`.

The expanded source dashboard and content review implementation is tracked in [PR #8](https://github.com/nightowlhoothoot83-create/Raven-Sharp-Smart-Cleaner-Web/pull/8); a source commit alone does not confirm a live deployment.
